# IFS Roofing Website

A multi-page website for a roofing and construction company, built on the RoofX Next.js template. It has many interchangeable banner, about, counter, appointment and blog sections.

## Features

- Reusable sections for banners, about, counters, appointments, brands, engineers and blog posts
- Blog list and post pages
- Sticky header, sidebar menu, preloader, back-to-top button and video popup
- Sitemap generated after each build (`next-sitemap`)
- Styles authored in SCSS

## Tech stack

Next.js, React, SASS, react-slick, react-modal-video, WOW.js, Playwright

## Getting started

```bash
npm install
npm run dev       # http://localhost:3000
```

| Script | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build (also generates the sitemap) |
| `npm start` | Run the production build |
| `npm run lint` | Lint with Next.js |
| `npm run sass` | Watch and compile `public/assets/scss/main.scss` to CSS |
